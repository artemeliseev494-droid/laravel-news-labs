# Новостной портал (Laravel)

Веб-приложение новостного сайта на Laravel.

## Функционал
- Просмотр новостей и фильтрация по категориям
- Регистрация и авторизация по логину и паролю
- Панель журналиста: публикация и редактирование собственных статей
- Панель администратора: модерация публикаций (блокировка, редактирование, удаление) и управление ролями пользователей
- Разграничение прав доступа с помощью Middleware

## Требования
- PHP 8.2+
- Composer
- SQLite или PostgreSQL

## Установка и запуск

1. Клонировать репозиторий:
```bash
git clone https://github.com/artemeliseev494-droid/laravel-news-labs.git
cd laravel-news-labs
```

2. Установить зависимости:
```bash
composer install
```

3. Настроить конфигурацию окружения:
```bash
cp .env.example .env
php artisan key:generate
```

4. Выполнить миграции и наполнить базу тестовыми данными:
```bash
php artisan migrate --seed
```

5. Запустить сервер разработки:
```bash
php artisan serve
```

Приложение будет доступно по адресу `http://127.0.0.1:8000`.
